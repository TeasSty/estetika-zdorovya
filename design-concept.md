## Unique thesis

1. Mood: спокойная ясность «кабинета у леса» — медицинская грамотность без больничной тоски; тело читают, а не «продают расслабление».
2. Type rationale: спокойный текстовый serif для имени/заголовков программ (человеческий голос специалиста) + humanist sans для протоколов, цен и UI (читаемость как у рабочей карты).
3. Palette logic: от штукатурки кабинета, дневного света у окна, хвои у леса и чернил аннотаций на программе — не от spa/luxury moodboard.
4. Composition: workshop-protocol — сайт как поэтапная карта восстановления (шаги 01–04), а не витрина салона.
5. Motion: медленные «перелистывания» этапов протокола и лёгкое проявление аннотаций; без glow и без SaaS-микропараллакса.
6. Main gesture: **аннотированная карта восстановления** — нумерованный протокол с пометками «как в индивидуальной программе», вокруг которого строятся секции.

## Palette + type

- Palette:
  - `--plaster`: `#E4E8E1` — основной фон (дневной свет + лёгкий зелёный оттенок стены)
  - `--sheet`: `#EEF2EC` — «лист программы» внутри протокола (холоднее cream-кластера)
  - `--ink`: `#242A27`
  - `--resin`: `#3E5644` (хвоя / лес у кабинета)
  - `--annotation`: `#6A4452` (чернильная пометка на карте — не градиент)
  - `--wood`: `#8F6A45` (стол / тёплый акцент CTA вторичного уровня)
  - `--mist`: `#CBD3C8` (разделители секций)
  - Explicit reject: `#F4F1EA` + terracotta pairing; purple/indigo gradients; gold accents
- Type:
  - Display / brand: **Literata** (или Fraunces) — мягкий «человеческий» serif под имя Любови и названия программ
  - Body / protocol UI: **Onest** (или Manrope) — ясный humanist sans для шагов, цен, форм
  - Numerals: tabular для цен и длительностей
